Peaky Minds Backend advanced. Дополнение 26.10.2026

Распакуйте целиком. Рабочая папка: student/lab. Python 3.12, venv создают внутри неё. Windows PowerShell: py -3.12 -m venv .venv, затем .venv/Scripts/python.exe -m pip install -r requirements.txt. Linux/macOS: python3.12 -m venv .venv и .venv/bin/python. Дальнейший python в руководствах означает этот полный путь; активация и смена ExecutionPolicy не нужны.

Basic: сначала первые Python/hello/preview, потом SQL и общий app. В app/main.py намеренно не завершена фиксация заявки: публичный тест сохранности должен выявить это до вашего ремонта. Compose называется peaky-backend-basic, PostgreSQL loopback:5432. В PowerShell задают $env:DATABASE_URL и $env:JWT_SECRET, в Bash — export. .env.example автоматически не читается. Используйте новый локальный секрет не короче 32 символов, не показывайте его в отчёте. Миграции выполняют до запуска uvicorn app.main:app. /users создаёт пользователя; /token получает форму, не JSON; POST /tickets требует Idempotency-Key. Изменённое тело того же ключа даёт конфликт, новое намерение получает новый ключ.

Advanced: новая отдельная распаковка, не папка basic. Остановите свой старый API на 8000. Из student/lab: docker compose up --build -d, затем logs migrate seed api. Проект peaky-backend-advanced-lantern; база loopback:55432; API loopback:8000; демонстрационный receiver loopback:8001. Не используйте down -v.

Advanced reservations: новое создание 201, повтор того же key/qty 200 с тем же id и replayed=true; конфликт qty 409. Эта редакция исправляет статус найденного повтора. public_smoke.py теперь проверяет эффект и завершается ошибкой при расхождении; это не полный экзамен. Нужна одна единица учебного остатка; исчерпанный остаток не лечат удалением старых бронирований.

Worker внутри Compose: docker compose exec -T -e DELIVERY_URL=http://receiver:8001/mock/events api python outbox_worker.py. Receiver принимает только демонстрацию: его accepted не доказывает durable inbox или подпись. Реализация этих свойств — ваша практика. faults.py содержит намеренно неверные token/cache/repeat адаптеры. auth.py содержит открытые demo labels, а security_jwt.py — отдельный пример: JWT зависимость нужно интегрировать по уроку, а не объявлять готовой.

Диски, таблицы и старые записи сохраняются. Полезное восстановление подтверждается прежним ID и значениями после нового процесса. Локальные результаты отдельно от баллов Stepik. Рабочий отчёт может быть TXT/Markdown/DOCX; финальная инструкция должна содержать точные команды и версии. Исторические DOCX редакции 2 сохранены как чтение, текущие уточнения — здесь и в Stepik. Обещанная постоянная преподавательская проверка и External Grader не подключены.
